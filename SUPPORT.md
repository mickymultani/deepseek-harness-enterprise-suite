# Support

Use GitHub Discussions for design questions and deployment patterns. Use GitHub Issues for reproducible defects and scoped feature proposals. Use private vulnerability reporting for security concerns.

Community support is best effort. The project does not provide an uptime, response-time, compatibility, or regulatory-compliance warranty. Organizations requiring contractual support should establish internal ownership or engage a qualified provider.

When requesting help, include the suite version, DeepSeek Harness version, Node.js version, operating system, relevant redacted configuration, exact command, expected result, and complete error message. Never include credentials or private enterprise content.
