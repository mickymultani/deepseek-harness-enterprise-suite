# Changelog

All notable changes are documented here. The project follows Semantic Versioning after 1.0; pre-1.0 minor releases may include compatibility changes that are called out explicitly.

## 0.1.0 — 2026-08-22

- Added the installable enterprise bundle.
- Added mock and live Atlassian connector modes.
- Added Confluence search and Jira read, create, and issue-review tools.
- Added project and space allowlists, DLP checks, and approval-gated writes.
- Added redacted local JSONL audit output.
- Added reusable connector utilities and plugin project generator.
- Added the enterprise plugin catalog, security model, deployment guide, governance, CI, and contributor documentation.
